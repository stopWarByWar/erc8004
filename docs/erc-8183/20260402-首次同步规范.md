# ERC-8183 更新记录 - 2026-04-02

## 变更摘要
首次在仓库中同步 `ERC-8183`（Agentic Commerce）规范，作为后续版本比对的基线。

## 详细变更

### 新增内容
- 规范定义：作业（job）、四状态机（Open → Funded → Submitted → Terminal）与单一 evaluator 完成/驳回权限
- 角色与作业数据：client/provider/evaluator、可选 provider 与 hook 地址
- 核心合约流程：`createJob`、`setProvider`、`setBudget`、`fund`、`submit`、`complete`、`reject`、`claimRefund`
- 可选 hook 机制：`IACPHook`、`beforeAction/afterAction`、数据编码与安全约束（含钩子不影响 `claimRefund`）
- 费用（Fees）、事件（Events）与设计动机/论证（Motivation/Rationale）
- 可选扩展：与 ERC-8004 的信誉/证明互操作、与 ERC-2771 的元交易（facilitator relay）
- 参考实现与安全考虑（Reference Implementation / Security Considerations）
