# AgenticCommerce.sol 更新记录 - 2026-04-22

## 变更摘要
Hook 接口从 IACPHook 更名为 IERC8183Hook，并新增 Provider 不能同时担任 Evaluator 的校验逻辑。

## 详细变更

### 修改内容
- **接口重命名**：Hook 接口从 `IACPHook` 更名为 `IERC8183Hook`（import、注释、ERC165 接口检测均同步更新）
- **新增错误类型**：`error ProviderCannotBeEvaluator()` — 防止 provider 和 evaluator 为同一地址
- **createJob 校验**：在创建任务时增加 `if (evaluator != address(0) && evaluator == provider) revert ProviderCannotBeEvaluator()` 检查
- **setProvider 校验**：在设置 provider 时增加 `if (provider_ == job.evaluator) revert ProviderCannotBeEvaluator()` 检查

### 删除内容
- 移除文件末尾缺失的换行符（现已补正）
