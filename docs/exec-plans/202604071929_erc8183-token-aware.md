## 0. 范围与验收口径

- [x] `commerce_actions` 新增 3 个字段（payment_token / token_symbol / budget_usd）
- [x] `commerce_scores` / `commerce_scores_global` 各新增 2 个字段（total_volume_usd / weighted_volume_usd_sum）
- [x] Indexer BudgetSet handler 填充 token 字段并写入快照缓存
- [x] 后续事件（funded/submitted/终态）从快照缓存复用 token 信息
- [x] Symbol + Decimals 缓存：同一 token 只调用一次 `ResolveTokenInfo()`（symbol + decimals 同时获取）
- [x] Price 快照：BudgetSet 时刻计算 budget_usd，后续不变

## 3. Indexer 层

目标文件：`indexer/processor/token.go`（新文件）

**NOTE**: `globalPriceCache.m` 必须在 init 时 make()，否则 panic

- [x] `TokenInfo` struct + `tokenInfoCache`：symbol + decimals 内存缓存
- [x] `ResolveTokenInfo()`：串行调用 symbol() + decimals()，缓存命中 0 RPC
- [x] `globalPriceCache` init： `m: make(map[string]tokenPriceEntry)`
- [x] `GetHistoricalUSDBudget()`：用 blockTimestamp（秒→DD-MM-YYYY）查历史价格
- [x] `GetCurrentUSDBudget()`：用于 cache miss fallback
- [x] `fetchPriceWithFallback()`：3级降级（Pro → Free → 默认 1）
- [x] `resolveGeckoID(ctx, platform, tokenAddr)`：静态映射优先，miss 则动态查询
- [x] `fetchGeckoIDByContract(ctx, platform, tokenAddr)`：CoinGecko API
- [x] `chainIDToPlatform` map
- [x] `staticTokenToGeckoID` map（4 个主流 token）
- [x] `jobBudgetCache`：sync.Map[jobID] → jobBudgetEntry
- [x] `SetJobBudgetCache()` / `GetJobBudgetFromCache()`

目标文件：`indexer/processor/commerce.go`

**现状**：`handleBudgetSet`（line 552）只写入 JobBudget，无 token 信息

**改动**：

- [x] `handleBudgetSet`：
  - 从 `ev.Token` 取 paymentToken（事件直接取，零 RPC）
  - 调用 `ResolveTokenInfo()` 获取 symbol + decimals
  - 调用 `GetHistoricalUSDBudget()` 计算 budgetUSD
  - 写入 `jobBudgetCache`
  - 写入 `commerce_actions` 时填充 `PaymentToken` / `TokenSymbol` / `BudgetUSD`

- [x] `fillTokenFieldsFromCache(jobID)` 辅助方法：
  - 先查 `jobBudgetCache`
  - Miss 时回退到链上查询 + `GetCurrentUSDBudget()`

- [x] `handleJobFunded`：调用 `fillTokenFieldsFromCache` 填充 token 字段
- [x] `handleJobSubmitted`：调用 `fillTokenFieldsFromCache` 填充 token 字段
- [x] `writeTerminalSignals`：调用 `fillTokenFieldsFromCache` 填充 token 字段
