## 0. 验收口径

- [x] `commerce_jobs.updated_at` 全量来自链上 `block_timestamp`（无 `time.Now()`）
- [x] `UpsertCommerceJob` 在 `UpdatedAt == 0` 时拒绝写入（error）
- [x] `BudgetSet` 事件写入：
  - [x] `budget` / `payment_token` / `token_symbol`
  - [x] `budget_usd` 使用 `GetHistoricalUSDBudget(..., block_timestamp)`
- [x] `JobCompleted/Rejected/Expired` 正确写入 `status` 与对应时间字段（on-chain）
- [x] 结算拆分事件 **不调用 receipt**，直接从 `FilterLogs` 消费并写入：
  - [x] `PaymentReleased` → `paid_amount` / `paid_amount_usd`
  - [x] `PlatformFeePaid` → `platform_fee_amount` / `platform_fee_usd`
  - [x] `EvaluatorFeePaid` → `evaluator_fee_amount` / `evaluator_fee_usd`
- [x] 幂等：重放同一批 logs 不会改变结果（除 `updated_at` 同值覆盖外无漂移）（已补 model 层 upsert 幂等测试）
- [x] 乱序：结算事件先到/后到均不 panic，并能写入对应 job（必要时先 create 默认 job）（已补 model 层 out-of-order 写入测试）
