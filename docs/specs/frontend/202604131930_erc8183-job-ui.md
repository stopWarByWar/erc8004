# ERC-8183 Job UI Frontend Spec（Job Browser / Job Detail）

本文面向前端开发（含前端 agent），给出**页面信息架构、组件拆分、交互与口径**以及**所需 API 调用规范与 TS 类型**。按本文即可直接进入实现，不必再反查后端实现细节。

设计基线：

- `docs/designs/202604101000_erc8183-job.md` 第 5 章（5.1~5.4）

接口基线（后端已实现）：

- 新增 Job API 前缀：`/agent/commerce/jobs`*
- 旧 commerce 相关接口仍在：`/agent/identity/commerce/*`（不在本文展开；本文只使用 `/agent/commerce/jobs*`）

响应封装约定（全站统一）：

- **HTTP 状态**：成功/失败都返回 **HTTP 200**
- **成功**：`{"code":0,"status":"success","msg":"","data":{...}}`
- **失败**：`{"code":1,"status":"failed","msg":"Invalid Request|Internal Error"}`

## 0. 关键口径（必须统一）

### 0.1 时间（on-chain）

- 列表/概览的“最后更新”使用 `commerce_jobs.updated_at`（unix 秒，链上 block_timestamp）
- 证据时间线/事件表使用 `commerce_actions.block_timestamp`（本 spec 只做入口声明；证据数据可后续扩展）

**展示格式**：

- 时间戳（unix 秒）前端统一格式化为：`YYYY-MM-DD HH:mm:ss`（本地时区），并在 tooltip 显示原始秒值
- 列表的默认排序与“Last Updated”均以 `updated_at` 为准（on-chain）

### 0.2 金额与 USD

- `budget_usd`：BudgetSet 时刻的历史 USD（非实时汇率）
- `paid_amount_usd/platform_fee_usd/evaluator_fee_usd`：结算事件时刻历史 USD
- **展示规则**：当 `status != completed`，Paid/Fee 一律展示 `—`（避免把 0 误读为“已结算为 0”）
- **无 USD**：显示 `—` + tooltip“价格源不可用”

**展示格式**：

- Token amount：按 `token_symbol` 展示，保留 2~6 位小数（前端可按金额量级动态截断）
- USD：统一以 `$` 前缀展示，默认 2 位小数；超大数值用紧凑格式（例如 `12.3K`/`4.5M`），tooltip 展示完整值

### 0.4 地址（Address）

- 展示：`0x1234…abcd`（前 6 + 后 4）
- 交互：
  - 点击 copy 图标：复制完整地址
  - 点击外链图标：跳对应链浏览器（链浏览器 base 由前端配置 `chain_id -> explorer` 映射）

### 0.3 状态枚举

`status` ∈ `open | funded | submitted | completed | rejected | expired`

## 1. 页面与路由

### 1.1 Job List（Job Browser）

- **Route**：`/jobs`（前端路由，可自定）
- **数据来源**：
  - 列表：`GET /agent/commerce/jobs`
  - 顶部概览：`GET /agent/commerce/jobs/general`（filters 同步）
  - 图表：`GET /agent/commerce/jobs/charts`（filters 同步）

### 1.2 Job Detail

- **Route**：`/jobs/:chainId/:contract/:jobId`
- **数据来源**：`GET /agent/commerce/jobs/detail`
- **证据区**：本期先渲染结构与入口（`evidence`），时间线/事件表可后续接入（若已有 actions API，也可先按需接）

## 2. UI：Job List（P0）

### 2.1 Layout（推荐）

- Top：`JobsGeneralBar`（Summary Bar，P0）
- Next：`ChartsGallery`（5.4，P0/P1 可折叠）
- Main：`JobsTable`（列表，P0）
- Right/Drawer（可选）：`FiltersPanel`（P0）

### 2.2 JobsTable 列定义（≤8 个锚点）

**展示字段（P0）**：


| UI 字段      | 数据字段                                           | 展示规则                                                                                          |
| ---------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Job ID     | `chain_id` + `commerce_contract` + `job_id`    | 主展示 `job_id`；`chain_id`/`contract` 作为 tag/tooltip；提供 copy                                     |
| Status     | `status`                                       | badge：completed=正向，rejected=负向，expired=中性灰，其余为进行中                                             |
| Budget     | `token_symbol` + `budget` + `budget_usd`       | 主行：`${token_symbol} ${budget}`；副行：`$budget_usd`（若无 USD 显示 `—`）                                |
| Paid (USD) | `token_symbol + paid_amount + paid_amount_usd` | 仅 `completed` 显示 `${token_symbol} ${paid_amount}`；副行：`$paid_amount_usd`（若无 USD 显示 `—`）；否则 `—` |
| Updated    | `updated_at`                                   | on-chain 时间；显示格式见 0.1                                                                         |


**展示字段（P1，可选）**：


| UI 字段        | 数据字段                        | 展示规则                              |
| ------------ | --------------------------- | --------------------------------- |
| Participants | `client/provider/evaluator` | 仅展示截断地址；hover 展示完整地址；copy/外链见 0.4 |


### 2.3 Job List 用户交互（必须实现）

**Row click**：

- 点击 `job_id` 或整行：进入 Job Detail：`/jobs/:chainId/:contract/:jobId`

**Copy**：

- `job_id`：复制 `chain_id + contract + job_id` 的 share string（推荐：`chain_id:contract:job_id`）
- `contract`、参与者地址：复制完整值

**Sorting**：

- 支持列排序：
  - Updated：`sort_by=updated_at&sort_order=desc|asc`
  - Budget USD：`sort_by=budget_usd&sort_order=desc|asc`
  - Paid USD：`sort_by=paid_amount_usd&sort_order=desc|asc`
- 切换排序时：重置 `page=1`

**Pagination**：

- `page/page_size` 与 URL query 同步（可复制分享）

**Filters**：

- 页面顶部必须展示 Filter chips（可删除单个条件、可一键 Clear all）
- 任一 filters 变化：触发三连刷新（list/general/charts），并重置 `page=1`

**Empty/Loading/Error**：

- loading：列表 skeleton（5~10 行）
- empty：展示“暂无 Jobs”（保留 filters 与清空按钮）
- error（`code=1`）：展示错误信息（`msg`），并提供 Retry

## 3. UI：Jobs General（P0）

### 3.1 Summary Bar（最多 6 张卡）

数据来自 `GET /agent/commerce/jobs/general` 的 `summary`：

- Jobs（Count）：`jobs_count`
- Paid Volume (USD)：`paid_volume_usd`（可点击自动加筛选 `status=completed`）
- Budget Volume (USD)：`budget_volume_usd`
- Outcome Mix：`outcome_mix.completed/rejected/expired`（点击 segment → `status=<segment>`）
- Active Mix：`active_mix.open/funded/submitted`（点击 → `status` 过滤或 `status in (...)` 前端组合）
- Last Updated：`last_updated`

### 3.1.1 Summary Bar 用户交互（必须实现）


| 卡片/区域                 | 点击行为        | filters 变化                               |
| --------------------- | ----------- | ---------------------------------------- |
| Paid Volume (USD)     | 下钻到已完成 Jobs | `status=completed`                       |
| Outcome Mix 的 segment | 下钻到对应状态     | `status=<completed|rejected|expired>`    |
| Active Mix 的 segment  | 下钻到对应状态     | `status=<open|funded|submitted>`         |
| Token 分布的一行           | 下钻到 token   | `token_symbol=<token>`                   |
| Chain/Contract 分布的一行  | 下钻到分段       | `chain_id=<id>&commerce_contract=<addr>`（**展示**：chain name + chain logo + `commerce_contract`） |


> 下钻后：重置 `page=1`，并触发 list/general/charts 刷新。

### 3.2 Distribution Row（P1，可折叠）

数据来自 `distributions`：

- Token：按 `token_symbol` 的 `jobs_count/budget_volume_usd/paid_volume_usd`
- Chain/Contract：按 `chain_id + commerce_contract`（展示：chain name + chain logo + `commerce_contract`；chain 元信息来自 network 列表/静态映射）
- Fees：`platform_fee_usd/evaluator_fee_usd`

> UI 必须提示：“指标随筛选变化”，并显式展示当前 filters（可复制分享）。

## 4. UI：Charts Gallery（5.4）

### 4.1 目标

从多个维度展示活跃度/健康度/规模/结构，并支持从图表**下钻**到 Job List（filters）或 Job Detail。

### 4.2 数据接口

- `GET /agent/commerce/jobs/charts`
- 前端将当前 filters 原样带上（与 list/general 一致）
- 图表条目会携带 `drilldown`（对象），前端点击后将其 merge 到当前 filters 并刷新 list/general/charts

### 4.4 图表展示项与交互（P0 必须）

前端至少实现以下图表（允许先做简版，保证下钻一致）：

#### 4.4.1 Activity

- `active_jobs_over_time[]`
  - 展示：折线/柱状均可
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）
- `created_jobs_over_time[]`
  - 展示：折线/柱状均可（表示“新增 jobs”，按 JobCreated 落桶）
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）
- `unique_clients_over_time[]`
  - 展示：折线/柱状均可（桶内 client 地址去重计数）
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）
- `unique_providers_over_time[]`
  - 展示：折线/柱状均可（桶内 provider 地址去重计数）
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）

#### 4.4.2 Health

- `outcome_mix[]`（环形/堆叠条）
  - 点击 segment：merge `drilldown`（含 `status`）
- `funnel[]`（漏斗）
  - 点击 stage：merge `drilldown`（含 `status`）

#### 4.4.3 Volume

- `paid_volume_usd_over_time[]`
  - 点击桶：merge `drilldown`（含 `status=completed` + 时间窗）
- `platform_fee_usd_over_time[]`
  - 点击桶：merge `drilldown`（含 `status=completed` + 时间窗）
- `fees_breakdown[]`（环形/堆叠）
  - 点击 segment：merge `drilldown`（默认 `status=completed`）

#### 4.4.4 Distribution

- `token_distribution[]`
  - 点击 token：merge `drilldown`（含 `token_symbol`）
- `chain_contract_distribution[]`
  - 点击：merge `drilldown`（含 `chain_id/commerce_contract`）
- `budget_histogram_usd[]`
  - 点击区间：merge `drilldown`（含 `min_budget_usd/max_budget_usd`）

#### 4.4.5 Evidence

- `top_events[]`
  - 点击条目：跳 Job Detail（drilldown 含 `chain_id/contract/job_id`）

### 4.3 图标语义（前端资源规范）

- Status：open=待办/空心圆，funded=锁，submitted=上传，completed=对勾，rejected=叉，expired=时钟
- Money：budget=标签/票据，paid=转账箭头，platform_fee=收据，evaluator_fee=天平/徽章
- Dimension：token=硬币，chain=链环，contract=文档/合约，time=时钟

## 5. UI：Job Detail（P0）

### 5.1 Header（吸顶摘要条）

- 标识：`chain_id`、`commerce_contract`（copy）、`job_id`
- 状态：`status`
- 时间：`updated_at`
- 主金额：`token_symbol` + `budget`（小字 `budget_usd`）
- 快捷入口：
  - `ViewInFeed`（可先隐藏，后续接全局活动流）
  - `ViewTimeline`（滚动到证据区）

### 5.1.1 Header 展示字段（P0）


| UI 字段        | 数据字段                             | 展示规则               |
| ------------ | -------------------------------- | ------------------ |
| Job ID       | `job_id`                         | 主标题                |
| Chain        | `chain_id`                       | tag；用于 explorer 选择 |
| Contract     | `commerce_contract`              | 截断 + copy + 外链     |
| Status       | `status`                         | badge（同 list）      |
| Last Updated | `updated_at`                     | on-chain 时间        |
| Budget       | `token_symbol/budget/budget_usd` | 同 list             |


### 5.2 概览区 Cards

- `ParticipantsCard`：client/provider/evaluator（地址 copy + 外链）
- `MoneyCard`：
  - Budget：`budget` + `budget_usd`
  - Paid：`paid_amount` + `paid_amount_usd`（仅 completed，否则 `—`）
  - Fees：platform/evaluator（仅 completed，否则 `—`）
- `SignalsCard`：本期可先不接（若要接，走旧 `agent/identity/commerce/actions` 的 signal 字段；后续单独 spec）

### 5.2.1 ParticipantsCard 展示字段与交互（P0）


| 角色        | 数据字段        | 交互                           |
| --------- | ----------- | ---------------------------- |
| Client    | `client`    | copy / explorer 外链           |
| Provider  | `provider`  | 若为空显示 `—`；copy / explorer 外链 |
| Evaluator | `evaluator` | 若为空显示 `—`；copy / explorer 外链 |


### 5.2.2 MoneyCard 展示字段（P0）


| 区块            | 数据字段                                         | 展示规则                          |
| ------------- | -------------------------------------------- | ----------------------------- |
| Budget        | `budget` + `budget_usd`                      | 永远显示（USD 不可用则 `—`）            |
| Paid (net)    | `paid_amount` + `paid_amount_usd`            | `status=completed` 才显示，否则 `—` |
| Platform Fee  | `platform_fee_amount` + `platform_fee_usd`   | `status=completed` 才显示，否则 `—` |
| Evaluator Fee | `evaluator_fee_amount` + `evaluator_fee_usd` | `status=completed` 才显示，否则 `—` |


### 5.3 证据区（P1，先结构后数据）

`/agent/commerce/jobs/detail` 返回 `evidence`：

- `timeline_source` / `events_table_source`（字符串，用于展示“来源”）
- `settlement_events`（列表，用于 UI 标签/说明）

后续若要接数据：

- Timeline/EventsTable 可读取 `commerce_actions`（需要单独 endpoint 或复用现有 actions API 并按 job 过滤）

## 6. Filters（Job List / General / Charts 共用）

### 6.1 Filters schema（前端 state）

- chain：`chain_id?` + `commerce_contract?`
- status：单选 `status?`
- token：`token_symbol?` / `payment_token?`
- money：
  - `min_budget?` / `max_budget?`
  - `min_budget_usd?` / `max_budget_usd?`
- time：`start_time?` / `end_time?`（unix 秒）
- sort：`sort_by?` + `sort_order?`
- paging：`page` + `page_size`

### 6.2 统一下钻规则（Charts / General / Table）

- 点击事件携带的 `drilldown`（对象）直接 merge 到 filters（同 key 覆盖）
- merge 后：
  - 重置 `page=1`
  - 触发三连刷新：list + general + charts

### 6.3 URL 同步（必须）

- filters + sort + paging 必须与 URL query 双向同步（可复制分享）
- 进入页面时从 URL 初始化 state
- drilldown merge 后必须更新 URL

## 7. API：Endpoints（/agent/commerce/jobs*）

### 7.0 通用返回（必须理解）

无论成功/失败均为 HTTP 200，前端必须以 `code` 判定。

**成功**：`ApiOk<T>`

```json
{ "code": 0, "status": "success", "msg": "", "data": {} }
```

**失败**：`ApiErr`

```json
{ "code": 1, "status": "failed", "msg": "Invalid Request" }
```

### 7.1 GET `/agent/commerce/jobs`（List）

- `commerce_contract`
- `status`
- `payment_token`
- `token_symbol`

- `min_budget_usd` / `max_budget_usd`

```ts
export type ApiOk<T> = { code: 0; status: "success"; msg: ""; data: T };
export type ApiErr = { code: 1; status: "failed"; msg: "Invalid Request" | "Internal Error" };
export type ApiResp<T> = ApiOk<T> | ApiErr;

export type JobStatus = "open" | "funded" | "submitted" | "completed" | "rejected" | "expired";

export type CommerceJob = {
  chain_id: string;
  commerce_contract: string;
  job_id: number;
  status: JobStatus;
  updated_at: number;

  client: string;
  provider: string;
  evaluator: string;
  description?: string;
  hook_address?: string;

  expired_at: number;
  submitted_at: number;
  completed_at: number;

  payment_token: string;
  token_symbol: string;

  budget: number;
  budget_usd: number;
  paid_amount: number;
  paid_amount_usd: number;
  platform_fee_amount: number;
  platform_fee_usd: number;
  evaluator_fee_amount: number;
  evaluator_fee_usd: number;

  latest_block_number?: number;
  latest_tx_hash?: string;
  latest_action_uid?: number;
};

export type JobsListData = { jobs: CommerceJob[]; total: number };

export type JobDetailData = {
  job: CommerceJob;
  evidence: {
    timeline_source: string;
    events_table_source: string;
    settlement_events: string[];
  };
};

export type JobsGeneralData = {
  summary: {
    jobs_count: number;
    paid_volume_usd: number;
    budget_volume_usd: number;
    outcome_mix: { completed: number; rejected: number; expired: number };
    active_mix: { open: number; funded: number; submitted: number };

  };
  distributions: {
    token: Array<{ token_symbol: string; jobs_count: number; budget_volume_usd: number; paid_volume_usd: number }>;

  };
};

export type Drilldown = Record<string, unknown>;
export type JobsChartsData = {
  charts: {
    activity: {
      active_jobs_over_time: Array<{ bucket: number; count: number; drilldown: Drilldown }>;
    };

      funnel: Array<{ stage: JobStatus; count: number; drilldown: Drilldown }>;
```

## 9. 前端验收 Checklist（P0）

- filters 改变时：list/general/charts 同步刷新，且页面显式展示当前 filters（可复制）
- `status != completed`：Paid/Fee 均显示 `—`
- charts/general 点击能下钻回填 filters，`page` 重置为 1
- API 错误：HTTP 200 但 `code=1` 时页面显示错误态（保留 filters）
