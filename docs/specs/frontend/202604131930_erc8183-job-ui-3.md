# ERC-8183 Job UI Frontend Spec（Job Browser / Job Detail）

本文面向前端开发（含前端 agent），给出**页面信息架构、组件拆分、交互与口径**以及**所需 API 调用规范与 TS 类型**。按本文即可直接进入实现，不必再反查后端实现细节。

设计基线：

- `docs/designs/202604101000_erc8183-job.md` 第 5 章（5.1~5.4）

接口基线（后端已实现）：

- 新增 Job API 前缀：`/agent/commerce/jobs`*
- 旧 commerce 相关接口仍在：`/agent/identity/commerce/`*（不在本文展开；本文只使用 `/agent/commerce/jobs*`）

响应封装约定（全站统一）：

- **HTTP 状态**：成功/失败都返回 **HTTP 200**
- **成功**：`{"code":0,"status":"success","msg":"","data":{...}}`
- **失败**：`{"code":1,"status":"failed","msg":"Invalid Request|Internal Error"}`

## 0. 关键口径（必须统一）

### 0.1 时间（on-chain）

- 列表/概览的“最后更新”使用 `commerce_jobs.updated_at`（unix 秒，链上 block_timestamp）
- 证据时间线/事件表使用 `commerce_actions.block_timestamp`（本 spec 只做入口声明；证据数据可后续扩展）

**展示格式**：

- 时间戳（unix 秒）前端统一格式化为：`YYYY-MM-DD HH:mm:ss`（本地时区），并在 tooltip 显示原始秒值
- 列表的默认排序与“Last Updated”均以 `updated_at` 为准（on-chain）

### 0.2 金额与 USD

- `budget_usd`：BudgetSet 时刻的历史 USD（非实时汇率）
- `paid_amount_usd/platform_fee_usd/evaluator_fee_usd`：结算事件时刻历史 USD
- **展示规则**：当 `status != completed`，Paid/Fee 一律展示 `—`（避免把 0 误读为“已结算为 0”）
- **无 USD**：显示 `—` + tooltip“价格源不可用”

**展示格式**：

- Token amount：按 `token_symbol` 展示，保留 2~6 位小数（前端可按金额量级动态截断）。列表与详情接口均返回 `payment_decimals`（链上 ERC20 decimals；库内为 0 时后端归一为 18），可与 `budget`/`paid_amount` 等字符串金额一起用于格式化或校验
- USD：统一以 `$` 前缀展示，默认 2 位小数；超大数值用紧凑格式（例如 `12.3K`/`4.5M`），tooltip 展示完整值

### 0.4 地址（Address）

- 展示：`0x1234…abcd`（前 6 + 后 4）
- 交互：
  - 点击 copy 图标：复制完整地址
  - 点击外链图标：跳对应链浏览器（链浏览器 base 由前端配置 `chain_id -> explorer` 映射）

### 0.3 状态枚举

`status` ∈ `open | funded | submitted | completed | rejected | expired`

## 2. UI：Job List（P0）

### 2.0 页面头部文案（P0）

- 标题：`ERC-8183 Jobs`
- 副标题：`Browse and analyze on-chain commerce jobs on ERC-8183.`（**不显示 total 数字**：因为列表可能随时新增，展示实时 total 容易误导；详细计数交给分页区展示）

### 2.1 Layout（推荐）

- Top：`JobsGeneralBar`（Summary Bar，P0；**不再包含 Distributions 区**）
- Next：`DistributionsPanel`（Fees Breakdown / Token Distribution / Chain / Contract，P0；数据源统一改为 `/charts`，以便支持两级 Chain / Contract 与统一 `drilldown` 语义）
- Next：`ChartsGallery`（5.4，P0/P1 可折叠；**移除** Top Events 与 Budget Histogram (USD) 卡片，接口保留不调用）
- Main：`JobsTable`（列表，P0）
- Right/Drawer（可选）：`FiltersPanel`（P0）

### 2.2 JobsTable 列定义（≤8 个锚点）

**展示字段（P0）**：


| UI 字段   | 数据字段                                           | 展示规则                                                                                          |
| ------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Job ID  | `job_id` + `chain_id` + `commerce_contract` +（可选）`chain_name` + `chain_logo` | 主展示 `job_id`。**链信息**：有 `chain_logo` 时显示小图标（圆角，`img` + `alt`/`title` 用 `chain_name` 或 `chain_id`）；链名优先 `chain_name`，缺省则仅展示 `chain_id`。`commerce_contract` 用短地址 + tooltip 全文 + copy（规则见 0.4） |
| Status  | `status`                                       | badge：completed=正向，rejected=负向，expired=中性灰，其余为进行中                                             |
| Budget  | `token_symbol` + `budget` + `budget_usd`       | 主行：`${token_symbol} ${budget}`；副行：`$budget_usd`（若无 USD 显示 `—`）                                |
| Paid    | `token_symbol + paid_amount + paid_amount_usd` | 仅 `completed` 显示 `${token_symbol} ${paid_amount}`；副行：`$paid_amount_usd`（若无 USD 显示 `—`）；否则 `—` |
| Updated | `updated_at`                                   | on-chain 时间；显示格式见 0.1                                                                         |


**展示字段（P1，可选）**：


| UI 字段        | 数据字段                        | 展示规则                              |
| ------------ | --------------------------- | --------------------------------- |
| Participants | `client/provider/evaluator` | 仅展示截断地址；hover 展示完整地址；copy/外链见 0.4 |

**列表接口与链字段（P0，与 §7.1 对齐）**：

- `GET /agent/commerce/jobs` 返回的每条 job 与 detail 同源：服务端按 `chain_id` 解析链配置，**可选**填充 `chain_name`、`chain_logo`（URL 字符串；未命中配置时二者均可缺省，前端必须回退到仅展示 `chain_id`）
- **图片失败**：`chain_logo` 加载失败时隐藏坏图，回退为链名首字/省略图标，不得阻塞整表渲染
- **不得**在列表里硬编码链表：一律消费接口字段 + 前端已有的 `chain_id -> explorer`（仅用于地址外链，见 0.4）


### 2.3 Job List 用户交互（必须实现）

**Row click**：

- 点击 `job_id` 或整行：进入 Job Detail：`/jobs/:chainId/:contract/:jobId`

**Copy**：

- `job_id`：复制 `chain_id + contract + job_id` 的 share string（推荐：`chain_id:contract:job_id`）
- `contract`、参与者地址：复制完整值

**Sorting**：

- 支持列排序：
  - Updated：`sort_by=updated_at&sort_order=desc|asc`
  - Budget USD：`sort_by=budget_usd&sort_order=desc|asc`
  - Paid USD：`sort_by=paid_amount_usd&sort_order=desc|asc`
- 切换排序时：重置 `page=1`

**Pagination**：

- `page/page_size` 与 URL query 同步（可复制分享）

**Filters**：

- 页面顶部必须展示 Filter chips（可删除单个条件、可一键 Clear all）
- 任一 filters 变化：触发三连刷新（list/general/charts），并重置 `page=1`

**Empty/Loading/Error**：

- loading：列表 skeleton（5~10 行）
- empty：展示“暂无 Jobs”（保留 filters 与清空按钮）
- error（`code=1`）：展示错误信息（`msg`），并提供 Retry

## 4. UI：Charts Gallery（5.4）

### 4.1 目标

从多个维度展示活跃度/健康度/规模/结构，并支持从图表**下钻**到 Job List（filters）或 Job Detail。

### 4.2 数据接口

- `GET /agent/commerce/jobs/charts`
- 前端将当前 filters 原样带上（与 list/general 一致）
- 图表条目会携带 `drilldown`（对象），前端点击后将其 merge 到当前 filters 并刷新 list/general/charts

### 4.4 图表展示项与交互（P0 必须）

前端至少实现以下图表（允许先做简版，保证下钻一致）：

时间轴格式：X 轴 label 统一使用 `MM/DD`（**不带时分**），避免短窗口重复标签；tooltip 中的时间仍保留完整 `bucket` unix 秒以便调试。

#### 4.4.1 Activity

- `active_jobs_over_time[]`
  - 展示：折线/柱状均可
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）
- `created_jobs_over_time[]`
  - 展示：折线/柱状均可（表示“新增 jobs”，按 JobCreated 落桶）
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）
- `unique_clients_over_time[]`
  - 展示：折线/柱状均可（桶内 client 地址去重计数）
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）
- `unique_providers_over_time[]`
  - 展示：折线/柱状均可（桶内 provider 地址去重计数）
  - 点击桶：merge `drilldown`（含 `start_time/end_time`）

#### 4.4.2 Health

- `outcome_mix[]`（环形/堆叠条）
  - 点击 segment：merge `drilldown`（含 `status`）
- `funnel[]`（漏斗）
  - 点击 stage：merge `drilldown`（含 `status`）

#### 4.4.3 Volume

- `paid_volume_usd_over_time[]`
  - 点击桶：merge `drilldown`（含 `status=completed` + 时间窗）
- `platform_fee_usd_over_time[]`
  - 点击桶：merge `drilldown`（含 `status=completed` + 时间窗）

> `fees_breakdown[]` 已从 `ChartsGallery` 移出，改由 §4.5 `DistributionsPanel` 承接。

#### 4.4.4 Distribution（已迁移至 §4.5 `DistributionsPanel`）

`token_distribution[]` / `chain_contracts[]` 从 `ChartsGallery` 移出，由 §4.5 `DistributionsPanel` 承接。

`budget_histogram_usd[]` **前端暂不渲染**（接口保留，后端不改）。

#### 4.4.5 Evidence（前端暂不渲染）

`top_events[]` 从 `ChartsGallery` 移出，前端暂不渲染；接口保留，不调用。

### 4.5 DistributionsPanel（P0）

**位置**：`JobsGeneralBar` 与 `ChartsGallery` 之间（原 §3.2 Distributions Row 的位置）。

**数据源**：`/charts`（§7.4）返回的 `charts.volume.fees_breakdown` + `charts.distribution.token_distribution` + `charts.distribution.chain_contracts`。

**布局**：三个**独立 panel**（每个 panel 自带边框与标题，不再合并成一个 card）

- 第 1 行：`Fees Breakdown`（左）与 `Token Distribution`（右）并排；桌面端各占一半，移动端上下堆叠
- 第 2 行：`Chain / Contract` 单独一行、满宽


| 栏位                 | 字段来源                                        | 展示                                                                  | 点击                                                              |
| ------------------ | ------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------- |
| Fees Breakdown     | `charts.volume.fees_breakdown[]`            | `type` 标签（`platform_fee_usd` / `evaluator_fee_usd`） + USD 值         | 使用条目自带 `drilldown`                                              |
| Token Distribution | `charts.distribution.token_distribution[]`  | `token_symbol` + `jobs_count / budget_volume_usd / paid_volume_usd` | 使用条目自带 `drilldown`；缺省时 fallback `{ token_symbol }`              |
| Chain / Contract   | `charts.distribution.chain_contracts[]`（两级） | 见下                                                                  | 使用叶子 `drilldown`；缺省时 fallback `{ chain_id, commerce_contract }` |


**Chain / Contract 两级结构**：

- 第一级（组标题，可折叠）：`chain_logo` + `chain_name`（若缺，fallback `Chain ${chain_id}`）
- 第二级（组成员）：`erc8183_contracts[]` 每个合约独立一行
  - 左侧：`commerce_contract`（截断地址 `0x1234…abcd`，见 §0.4）
  - 右侧：`jobs_count jobs · budget $X · paid $Y`

> 若后端仍返回旧扁平结构 `chain_contract_distribution[]`（兼容 §7.4 旧 schema），前端按 `chain_id` 做一次分组回退。

### 4.3 图标语义（前端资源规范）

- Status：open=待办/空心圆，funded=锁，submitted=上传，completed=对勾，rejected=叉，expired=时钟
- Money：budget=标签/票据，paid=转账箭头，platform_fee=收据，evaluator_fee=天平/徽章
- Dimension：token=硬币，chain=链环，contract=文档/合约，time=时钟

## 6. Filters（Job List / General / Charts 共用）

### 6.1 Filters schema（前端 state）

- chain：`chain_id?` + `commerce_contract?`
- status：单选 `status?`
- token：`payment_token?`
- role：`role?` + `agent_address?`
- time：`start_time?` / `end_time?`（unix 秒）

> 这些字段若出现在 URL 上仍会参与请求；Active filter chips 也会展示并支持单独移除。

### 6.2 统一下钻规则（Charts / General / Table）

- 点击事件携带的 `drilldown`（对象）直接 merge 到 filters（同 key 覆盖）
- merge 后：
  - 重置 `page=1`
  - 触发三连刷新：list + general + charts

### 6.3 URL 同步（必须）

- filters + sort + paging 必须与 URL query 双向同步（可复制分享）
- 进入页面时从 URL 初始化 state
- drilldown merge 后必须更新 URL

## 7. API：Endpoints（/agent/commerce/jobs*）

### 7.0 通用返回（必须理解）

无论成功/失败均为 HTTP 200，前端必须以 `code` 判定。

**成功**：`ApiOk<T>`

```json
{ "code": 0, "status": "success", "msg": "", "data": {} }
```

**失败**：`ApiErr`

```json
{ "code": 1, "status": "failed", "msg": "Invalid Request" }
```

### 7.1 GET `/agent/commerce/jobs`（List）

Query（均可选，`page`/`page_size` 建议必传）：

- `chain_id`
- `commerce_contract`
- `status`（可省略或空字符串：表示不按状态过滤；非空时须为合法枚举）
- `payment_token`
- `token_symbol`
- `min_budget` / `max_budget`（按 token 原币口径，与库内 `budget` 比较）
- `min_budget_usd` / `max_budget_usd`（与 `/general`、`/charts` 同口径，便于图表下钻与 URL 分享）
- `start_time` / `end_time`（unix 秒，基于 `commerce_jobs.updated_at`）
- `role`（可选：client/provider/evaluator；用于按角色视角过滤）
- `agent_address`（可选：与 role 联动）
- `counterparty`（可选：与 role 联动）
- `sort_by`：`updated_at|budget|budget_usd|paid_amount_usd`（可省略，省略时后端按 `updated_at` 排序）
- `sort_order`：`asc|desc`（可省略，省略时后端默认 `desc`）
- `page` / `page_size`

**列表响应口径（与实现对齐）**：

- 每条 job 含 `job_uid`（库内主键，可做列表行 `key`）
- **`chain_name` / `chain_logo`（可选）**：由后端按 `chain_id` 从链配置解析，与 `GET .../detail` 的 job 对象同源；未配置时字段可省略，列表 UI 见 §2.2
- `budget` / `paid_amount` / `platform_fee_amount` / `evaluator_fee_amount` 均为**字符串**（固定最多 8 位小数再 trim，无科学计数法；与 detail 一致）
- `payment_decimals` 为**非 0 整数**（与 detail 一致；库内为 0 时后端按 18 返回）

返回 `data`：

- `jobs: CommerceJob[]`
- `total: number`

**返回 data 类型**：`JobsListData`

## 9. 前端验收 Checklist（P0）

- filters 改变时：list/general/charts 同步刷新，且页面显式展示当前 filters（可复制）
- Job List：当接口返回 `chain_name`/`chain_logo` 时正确展示；缺省或图片失败时回退到 `chain_id`，不硬编码链元数据
- `status != completed`：Paid/Fee 均显示 `—`
- charts/general 点击能下钻回填 filters，`page` 重置为 1
- API 错误：HTTP 200 但 `code=1` 时页面显示错误态（保留 filters）
